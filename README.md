# 기능정의 
	게임에서 벌어지는 일 / 서버가 해야 할 일

	게임을 켰다 / 사용자 인증, 사용자 중복 확인

	친구랑 같이 하고 싶다 / UDP형 브로드캐스트

	카드 내었다 / UDP형 브로드캐스트

	특정 도형이 5개가 되었다 / UDP형 브로드캐스트

	게임이 끝났다 / TCP형 브로드캐스트

	다시 접속했다 / 사용자인증, 중복확인

	할리갈리
	장르 : 보드게임

	인원 : 2 ~ 4명

	시간 : 없음

	규칙 : 같은 도형 5개일떄만 먼저 스페이스바를 누루면 승리
		   4개 이하일 떄 누를경우 체력(카드수)  -
		   1명이라도 카드가 0이면 게임 종료
		   종료 기준 카드를 가장 많이 보유한 사람이 승리

	조작 : 스페이스바, 마우스

# 패킷정의
	로그인 - 닉네임(string) - C2S
	로그인 결과 - 결과(bool) - S2C

	준비 - 준비버튼(Key) - C2S
	조작 - 카드 뒤집기(Key) / 벨(Key) - C2S

	시스템메세지 - 텍스트(string) - S2C
	나온 카드 전달 - 도형(string), 갯수(int) - S2C

	오답 - 잘못누른 유저(string), 카드-(int) - S2C
	게임 결과 - 승자)(string), 추가할 카드(int) - S2C
	게임 종료 - 승자 전달(string) - S2C
